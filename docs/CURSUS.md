# Cursus — Mayele Python Académie

## 1. Organisation LMD

| Cycle | Semestres | Crédits | Public visé | Titre délivré |
|---|---|---|---|---|
| **Licence 1** | S1–S2 | 60 | Débutant complet | Certificat Licence 1 |
| **Licence 2** | S3–S4 | 60 | Bases acquises | Certificat Licence 2 |
| **Licence 3** | S5–S6 | 60 | Spécialisation | **Licence Python** (mention de filière) |
| **Master 1** | S7–S8 | 60 | Licence validée | Certificat Master 1 |
| **Master 2** | S9–S10 | 60 | Master 1 validé | **Master Python** (mention de filière) |
| **Doctorat** | libre | — | Master validé | Contribution open source / recherche |

> Les titres sont des **certificats de l'académie**. Ce ne sont pas des diplômes d'État,
> sauf partenariat officiel avec un établissement reconnu.

Un crédit ≈ 25 heures de travail (cours, exercices, projet). Un module vaut 3 à 6 crédits.

## 4. Certificats

| Certificat | Condition |
|---|---|
| Attestation de module | Quiz et exercices ≥ 70 % |
| Certificat de parcours | Tous les modules + projet de synthèse validé |
| Licence / Master | Cycle complet (180 / 120 crédits) + projet noté |
| Badges de compétence | Git, SQL, Docker, FastAPI, etc. |

Chaque certificat porte un **numéro unique** et une **page de vérification publique** (QR code).

## 5. Règles pédagogiques

1. Un parcours est **terminé** (leçons, exercices, solutions, projets) avant le suivant.
2. Chaque concept est expliqué pour un novice : analogie, exemple minimal, puis généralisation.
3. Les exemples utilisent des situations locales (marché, boutique, transfert mobile, transport).
4. Tout code publié est **exécuté et testé** avant d'être livré.
5. Les versions des bibliothèques sont revues à chaque trimestre.
