# Modèle de leçon

Toutes les leçons (`parcours/*/lecons/lNN_sujet.md`) suivent ce plan.

```markdown
# Leçon X.Y — Titre court

⏱ Durée : 45 min · 🎯 Niveau : Débutant · 📦 Prérequis : leçon X.(Y-1)

## 🎯 Ce que tu sauras faire
- 3 à 4 objectifs concrets et vérifiables

## 1. Le problème (accroche)
Une situation réelle (ex. calculer la facture d'un client au marché).

## 2. L'idée en images
Analogie simple, schéma ASCII si utile.

## 3. Explication pas à pas
Code minimal → explication ligne par ligne → variantes.

## 4. ⚠️ Pièges courants
Les erreurs que font tous les débutants, avec le message d'erreur Python réel.

## 5. À retenir
Résumé en 5 lignes maximum.

## 6. Exercices
Liens vers exercices/exNN_*.py (3 à 5 exercices, tests automatiques).

## 7. Quiz
5 questions. Réponses en bas de page.
```

## Règles de rédaction

- Phrases courtes. Un terme technique = une définition à sa première apparition.
- Chaque bloc de code doit s'exécuter tel quel (sinon le dire explicitement).
- On montre l'erreur avant de montrer la correction.
- Les solutions des exercices contiennent la version « débutant » puis, si pertinent, la version « idiomatique ».
